# 页面设计与交互说明

## 1. 视觉方向

### 1.1 定调：深色地形沙盘

长征是一个在**真实地理上发生的**事件——雪山、草地、峡谷、渡口决定了每一次决策。所以视觉的第一原则是：**地形必须是主角，而不是一张灰色背景**。

选择了「深色数字沙盘」的路线：

- 高程色带从近黑的墨绿（低地）过渡到灰白（5000 米以上雪线），让四川盆地、云贵高原、青藏东缘、秦岭的地势差异一眼可辨；
- 西北方向 42° 高度角的光照，让山脉有立体起伏；
- 整体压暗，把亮度预算留给前景的红色路线。

对比参考站点（三维写实沙盘）的取舍：不追求三维，因为二维更容易看清「路线怎么走」这个核心信息，且加载成本低一个数量级。

### 1.2 色彩系统

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景 | `#080b10` | 近黑，让地形自己发光 |
| 底图冷雾 | `#04121c` @ 16% | 把地形推远，把前景拉近 |
| 省界 | `#2b3947` | 极淡，只提供方位参考 |
| 河流 | `#1e4d61` | 冷青，与红色路线形成温度对比 |
| 红一方面军 | `#e0443e` | 正红，叙事主轴 |
| 红二十五军 | `#e8a33d` | 橙金 |
| 红四方面军 | `#a259c4` | 紫 |
| 红二方面军 | `#3f8fd2` | 蓝 |
| 敌军 | `#4b86c6` | 冷蓝，与红二方面军的蓝靠位置与标注区分 |

四支队伍的配色不是随意取的：红一用正红（中央、主轴），其余三支用相互可辨的色相，避开与「敌军蓝」混淆的青色系。

### 1.3 字体

- **标题与诗词**：宋体系（`Songti SC` / `Source Han Serif SC`）——历史感、纪念碑感；
- **正文与 UI**：系统无衬线（`PingFang SC` / `Microsoft YaHei`）——可读性优先。

两种字体分工明确：凡是「被引用的历史文本」（标题、诗词）用宋体，凡是「产品在说话」（按钮、标注、说明）用无衬线。

### 分区职责

| 区域 | 内容 | 为什么放在这里 |
| --- | --- | --- |
| 顶部标识 | 标题、副标题、两个模式入口 | 视觉锚点，同时说明「这是什么时候、哪几支部队」 |
| 左侧图层控制 | 部队显隐（4 项）+ 节点类型显隐（6 项，带计数） | 常驻但可折叠；用户随时能瘦身画面 |
| 地图主区 | 地形 + 省界 + 河流 + 路线 + 节点 | 占满剩余空间，不做无谓分割 |
| 右侧详情抽屉 | 节点全文、事实表、诗词、分歧说明、出处 | 需要长文本阅读，抽屉比弹窗更不打断空间感 |
| 底部时间轴 | 播放/暂停、当前日期、大事摘要、变速、拖动条、节点刻度 | 时间维度是长征的核心变量，必须与空间并列 |
| 态势层（叠加） | 阶段列表 + 阶段叙述 + 双方兵力 | 战役级阅读需要沉浸，进入后隐藏总览 UI |

## 3. 交互设计

### 3.1 三种阅读节奏

设计上支持三种使用方式，对应三种粒度：

| 节奏 | 用户行为 | 界面响应 |
| --- | --- | --- |
| **概览** | 打开页面 | 自动 fitBounds 到长征走廊，路线以虚线显示「未来路线」 |
| **推进** | 点播放 / 拖时间轴 | 路线随日期逐段点亮，节点由暗转亮，行军光点沿路径移动 |
| **深读** | 点节点 / 进态势 | 抽屉展开全文；或切入战役级态势图层 |

### 3.2 时间轴的推进逻辑

时间轴不是简单的「进度条」，它做了三件事：

1. **路线连续切分**：预计算每支部队所有途经点的单调时间戳，任一时刻直接在当前推进点 `head` 处将路线切为 `past`（起点→`head`，连续生长的实线+光晕+前锋高亮尾迹）与 `future`（`head`→终点，始终保留的未走淡虚线），并在 `head` 旁实时挂出部队简称与当前分段标题；点击节点跨日期跳转时用 0.32 秒缓动平滑追赶，彻底消除整段切换的生硬感与中途断口；
2. **敌军态势随时间轴联动**：总览主图在路线下层叠加随日期淡入淡出的国民党军封锁线、合围圈与追堵箭头（四道封锁线、湘西口袋阵、川黔滇四十万合围、金沙江与大渡河防线、松潘与腊子口堵截、百丈关与乌蒙山围堵、西北静会截击），可在左侧面板独立开关；
3. **节点状态与文字防重叠联动**：13 个一级骨架节点默认常显短名称，放大时逐级展开二、三级节点名称并在屏幕像素空间自动避让翻转；日期晚于当前时刻的节点降透明度去饱和；
4. **事件摘要**：当前日期下方显示「截至此刻，最后发生的一件大事」，让用户不看地图也知道走到哪了。

播放速度 1× 约 56 秒走完 743 天（1934-10-10 → 1936-10-22），可 0.5×~4× 变速。

### 3.3 三级比例尺信息分级（Scale LOD）与战略地标

为避免全国总览画面拥挤，同时保证战役尺度具备充沛战术细节，全图元素按缩放比例尺严格分为三级：

| 比例尺层级 | 缩放区间 | 呈现内容 | 设计目的 |
| --- | --- | --- | --- |
| **L1 小比例尺（全国总览）** | `zoom < 5.45` | 四支红军路线、6 个战略转折锚点（瑞金/遵义/泸定桥/懋功/吴起镇/会宁）、每军 1 个极简番号签、淡色省名与柔和敌军轮廓 | 极简留白，让长征路线成为唯一视觉主角 |
| **L2 中比例尺（战区机动）** | `5.45 ≤ zoom < 6.75` | 13 个一级骨架节点名称、二级节点图标、**贵阳/昆明/泸州/宜宾/松潘等战略重镇城标**、主要江河、行军实时阶段挂签、战区级敌军箭头 | 浮现决定行军走向的省际战略支点与敌我大势 |
| **L3 大比例尺（战役沙盘）** | `zoom ≥ 6.75` | 三级全部节点、**茅台/太平渡/界首/打鼓新场等战术渡口要隘**、z=10 高精度战场地形、动态生长的敌我战术箭头、锯齿防线与激战脉冲波纹 | 完整支撑战役级敌我穿插与地理依托阅读 |

### 3.4 节点标注的交互

- **悬停**：节点放大 1.22 倍，名称标签从左侧滑入；
- **选中**：节点填色反转（背景填充、图标变深），标签常显，地图 flyTo 到该点（带 offset 让点位避开右侧抽屉）；
- **标签方向自适应**：节点落在视野右半边时，标签改为朝左伸出，避免溢出屏幕；
- **史实存疑提示**：`confidence !== 'high'` 的节点，外圈加一圈金色虚线环 + tooltip 说明。

### 3.5 详情抽屉的内容层级

一个节点的详情按「阅读深度递增」排列：

```
[类型徽章]  [置信度徽章]
标题（宋体 26px）
日期 · 地点
一句话摘要（左侧红色竖线）
正文段落（14px / 1.85 行高 / 两端对齐）
关键数字表（如有）
诗词卡片（仅 poem 类型，紫色底 + 宋体）
史料分歧说明（如有，金色警示框）
出处列表（带外链）
```

诗词用紫色而非红色，是为了把它从「军事叙事」里区分出来——它是一个不同性质的文本层。

### 3.6 六大战役动态场景剧场（主线贯通 + 镜头编排）

长征主路线全程留在沙盘上不断裂、不隐藏；围绕主线编排 **六大核心战役场景**（① 血战湘江、② 通道转兵、③ 四渡赤水·奇袭贵阳、④ 巧渡金沙江·飞夺泸定桥、⑤ 雪山草地·腊子口、⑥ 乌蒙回旋·三大主力大会师）：

1. **自适应镜头与时间流速**：开启「镜头跟随」播放时，进入核心战役自动平滑推近至战场比例尺并放缓时间流速（单节拍约 4.6 秒），演播结束后拉回走廊中景；用户一旦手拖或滚轮缩放地图，立即自动让出镜头控制权并显示「恢复镜头跟随」；
2. **渐进生长标绘动画**：`src/plot/plot.ts` 支持 `progress ∈ [0, 1]` 弧长截断生长，敌军合围圈与锯齿防线率先铺开、钳击箭头向外弧包抄合拢、红军穿插箭头迎面破局，激战点浮现脉冲波纹；
3. **战略支点聚光**：如「四渡赤水·奇袭贵阳」第四幕自动聚光高亮 **贵阳**（标注蒋介石驻节督战与滇军东援中计），直观呈现声东击西的战略精髓。

## 4. 关键设计决策记录

| 决策 | 选项 | 选择 | 理由 |
| --- | --- | --- | --- |
| 节点文字渲染 | maplibre symbol layer / DOM Marker | **DOM Marker** | 免 glyph 字体服务（离线可用），且能做悬停动效 |
| 底图来源 | 在线瓦片 / 预烘地形 | **预烘** | 零 key、零请求、完全离线；代价是深缩放会糊 |
| 态势标绘 | ol-plot / 自绘几何 | **自绘** | 需求是静态回放而非交互绘制，见 [技术栈调研](00-tech-stack.md) |
| 路线动画 | canvas 逐帧 / GeoJSON + dash | **GeoJSON + dash** | 数据量小，交给 maplibre 渲染更省心 |
| 页面框架 | React / 原生 TS | **原生 TS** | UI 复杂度中等，不值得引入框架与构建复杂度 |
| 时间轴范围 | 只显示红一方面军 / 全部两年 | **全部两年** | 三大主力会师是长征的终点，砍掉就讲不完整 |

## 5. 响应式

- **≥ 900px**：完整三栏（图层 / 地图 / 抽屉）+ 底部完整时间轴；
- **< 900px**：图层面板缩窄、变速按钮隐藏、态势阶段列表改为横向滚动条、态势卡片改为底部通栏。

地图本身用 `fitBounds` 自动适配，不依赖固定 zoom。

---

## 6. 可访问性要点

- 所有交互元素是原生 `<button>` / `<input type="range">`，键盘可达；
- 空格键播放/暂停，Esc 关闭抽屉与弹层；
- 节点 marker 带 `title` 属性，屏幕阅读器可读到「名称｜地点」；
- 置信度不只用颜色表达（同时有文字徽章「待考」「存疑」），不依赖单一感官通道。
