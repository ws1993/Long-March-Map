# Objective

制作一个红军长征地图项目（参考 https://xianggao1102.github.io/long_march_map/，仅作参考），目标是可视化展示长征全貌，具体内容包括：

1. **行军路线**：中央红军及红一、二、四方面军等各方面军的行军路线，并展示各部之间的关联事件（如会师）。
2. **重要节点标注**：重要会议（如遵义会议）、重要战役、人文要素（如毛主席在长征期间创作的诗词）、重要事件节点（如爬雪山、过草地）等，均需在地图上标注并支持查看说明。
3. **敌我作战态势**：呈现敌我双方的作战态势，例如四渡赤水期间双方兵力与运动的态势图。

并按指定顺序推进，每步先给方案再实施：

1. 收集数据（注明来源、确保准确、标注争议）；
2. 设计页面样式（布局与交互，先说明再动手）；
3. 制作二维态势（先做局部如四渡赤水验证，再扩展）；
4. 调研对比 maplibre 自绘与 ol-plot + OpenLayers，给出结论和理由后再定技术栈。

# Acceptance criteria

1. 项目可构建：`npm run build` 退出码为 0，产出 dist/。
2. 类型检查干净：`npx tsc --noEmit` 无任何错误输出。
3. 路线数据覆盖四支主力部队，每条分段带日期区间、途经点与置信度。
4. 节点数据覆盖会议/战役/自然险阻/诗词/事件/会师六类，每个节点带 `source` 与 `confidence`。
5. 四渡赤水态势数据包含双方兵力、指挥关系、五个阶段的时间与标绘图形定义。
6. 三份方案文档存在：技术栈调研（含 maplibre 自绘 vs ol-plot 的结论与理由）、数据来源与置信度说明、页面设计与交互说明。
7. 页面在浏览器中实际渲染出地形底图、四支队伍不同颜色的路线、分级显示的节点标注。
8. 时间轴推进能改变地图状态（路线切分为已走/进行中/未走，节点由暗转亮）。
9. 点击节点能打开详情抽屉，渲染标题、日期地点、正文、事实表/诗词、出处。
10. 「作战态势」能进入四渡赤水态势模式，显示标绘图形与阶段叙述，并可切换阶段。
11. 「关于数据」弹层可打开并显示史料口径、坐标误差、标绘性质说明。
12. 底图与数据全部本地化：无在线瓦片服务、无地图 API key 依赖。
